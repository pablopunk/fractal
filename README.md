## Features

- 💅 Boring UI
- 💻 Supports ALL CLI agents. Claude code, pi, codex, you name it. No hacks, just tmux.
- 🗂️ Turn your ideas into prompts. Write down all your thoughts, tackle later.
- 🪾 Worktrees. Only when you need them.
- 📊 Kanban style. Drag and drop prompts like if they were tasks.
